## Challenge (what we must solve)

Turn the Sireț3 ortho (311 GeoTIFF tiles, 2.5 cm/px, EPSG:32635) into:

1. Per-plant `vineyard` polygons, `waste` boxes, `row` polylines, `interrow_area` polygons, with official attributes and stable IDs across tile edges.
2. Those labels **in Marcaj** (upload tiles + pre-annotations, correct only there, submit every job).
3. Two closed walks from the official start (inspector = gaps + waste; farmer = waste only), legal on inter-row ∪ passages − forbidden.
4. `measurements.csv` (jury) + `route.geojson` + `route_farmer.geojson` in the repo (32635).
5. A working web map (both walks, IDs, areas, counts).

Imagery is public and mostly **unlabeled**. The only official Sireț3 plant labels we may train on are the two example tiles (not scored). Drawing the 311 tiles outside Marcaj is forbidden. Hidden score tiles include **empty** frames.

The plants are young: small green tuft + long shadow + often a white tube. Much of the 311 grid is village, forest, or bare ground.

## How we are scored

Admission first (binary): published Marcaj + all jobs submitted + correct formats/CRS + working UI. Fail = no prize.

| % | What | Source |
| --- | --- | --- |
| 25 | Canopy IoU + per-plant F1 (IoU ≥ 0.5). Whole-row blob fails F1. False plants on empty tiles cost extra. | Marcaj `vineyard` |
| 10 | Waste box F1 (IoU ≥ 0.3). False = miss. Tubes/stakes are not waste. | Marcaj `waste` |
| 15 | Row-axis F1 (8%) + attribute acc/F1 (5%) + ID grouping (2%) | Marcaj `row` / `interrow_area` |
| 10 | Block count, row count, canopy ha, inter-row ha, row length (15% / 10% tolerance) | **Recomputed from Marcaj** |
| 25 | Inspector coverage (15%) + efficiency (10%). Instant 0 if >2% illegal or not closed ±5 m. Farmer file required, not this 25%. | Repo `route.geojson` |
| 15 | Architecture, robustness, scale, README timings | Repo + demo |

Ties: inspector route, then canopy, then jury.
